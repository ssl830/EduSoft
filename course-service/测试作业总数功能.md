# 作业总数功能测试文档

## 功能概述

course-service现在可以与content-service通信，获取课程的作业总数，解决之前作业总数总是0的问题。

## 修改内容

### 1. Content Service 修改
- 在 `HomeworkMapper` 中添加了 `countByCourseId` 方法
- 在 `HomeworkService` 中添加了 `getHomeworkCountByCourse` 方法
- 在 `HomeworkController` 中添加了 `/api/content/homework/count/course/{courseId}` 接口

### 2. Course Service 修改
- 添加了 OpenFeign 依赖
- 创建了 `ContentServiceClient` 接口
- 在 `CourseServiceImpl` 中添加了 `fetchHomeworkCountByCourseId` 方法
- 修改了 `getCourseDetailById`、`getCourseDetailsByUserId`、`getAllCourses` 方法，添加作业总数获取

## 测试步骤

### 1. 启动服务
```bash
# 启动 content-service (端口 8083)
cd content-service
mvn spring-boot:run

# 启动 course-service (端口 8082)
cd course-service
mvn spring-boot:run
```

### 2. 测试 Content Service 接口
```bash
# 测试作业总数统计接口
curl -X GET "http://localhost:8083/api/content/homework/count/course/1"
```

预期响应：
```json
{
  "success": true,
  "message": "获取作业总数成功",
  "data": 3,
  "code": 200
}
```

### 3. 测试 Course Service 接口
```bash
# 测试获取课程详情（包含作业总数）
curl -X GET "http://localhost:8082/api/course/1" \
  -H "satoken: your-token-here"
```

预期响应中的 `homeworkCount` 字段应该显示实际的作业总数，而不是0。

### 4. 验证数据库数据
确保 content-db 数据库中的 homework 表有测试数据：

```sql
-- 查看作业数据
SELECT * FROM homework WHERE course_id = 1;

-- 统计课程1的作业总数
SELECT COUNT(*) FROM homework WHERE course_id = 1;
```

## 故障排除

### 1. 如果作业总数仍然为0
- 检查 content-service 是否正常启动
- 检查 course-service 的配置文件中的 content.service.url 是否正确
- 查看 course-service 的日志，确认是否成功调用 content-service

### 2. 如果出现连接错误
- 确认 content-service 在端口 8083 上运行
- 检查防火墙设置
- 查看网络连接

### 3. 如果出现编译错误
- 确认已添加 OpenFeign 依赖
- 确认已启用 `@EnableFeignClients` 注解
- 检查 ContentServiceClient 接口定义是否正确
