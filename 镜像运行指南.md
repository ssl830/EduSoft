# EduSoft 微服务系统 - 镜像部署运行指南

## 📦 前提条件

确保你已经从 Docker Hub 拉取了以下 7 个镜像：

```bash
docker pull fankeqing/edusoft:mysql
docker pull fankeqing/edusoft:user-service  
docker pull fankeqing/edusoft:course-service
docker pull fankeqing/edusoft:content-service
docker pull fankeqing/edusoft:learning-service
docker pull fankeqing/edusoft:ai-service
docker pull fankeqing/edusoft:frontend
```

## 🚀 容器创建和运行指南

### 第一步：创建网络

```bash
# 创建自定义网络，让容器间可以通信
docker network create edusoft-network
```

### 第二步：按顺序启动容器

#### 1. 启动 MySQL 数据库（必须第一个启动）

```bash
docker run -d \
  --name edusoft-mysql \
  --network edusoft-network \
  -p 3307:3306 \
  -e MYSQL_ROOT_PASSWORD=fkq200566 \
  -e MYSQL_DATABASE=user-db \
  -v edusoft-mysql-data:/var/lib/mysql \
  --restart unless-stopped \
  fankeqing/edusoft:mysql

# 等待数据库启动完成（重要！等待30-60秒）
echo "等待数据库启动..."
sleep 60
```

#### 2. 启动用户服务

```bash
docker run -d \
  --name edusoft-user-service \
  --network edusoft-network \
  -p 8081:8081 \
  -e SPRING_DATASOURCE_URL="jdbc:mysql://edusoft-mysql:3306/user-db?useUnicode=true&characterEncoding=utf8&useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=Asia/Shanghai" \
  -e SPRING_DATASOURCE_USERNAME=root \
  -e SPRING_DATASOURCE_PASSWORD=fkq200566 \
  --restart unless-stopped \
  fankeqing/edusoft:user-service

# 等待服务启动
sleep 30
```

#### 3. 启动课程服务


## 🛠️ 管理命令

### 查看容器状态
```bash
docker ps
```

### 查看日志
```bash
# 查看特定服务日志
docker logs edusoft-user-service
docker logs edusoft-mysql

# 实时查看日志
docker logs -f edusoft-user-service
```

### 重启服务
```bash
# 重启特定服务
docker restart edusoft-user-service

# 重启所有服务
docker restart edusoft-mysql edusoft-user-service edusoft-course-service edusoft-content-service edusoft-learning-service edusoft-ai-service edusoft-frontend
```

### 停止所有服务
```bash
docker stop edusoft-frontend edusoft-ai-service edusoft-learning-service edusoft-content-service edusoft-course-service edusoft-user-service edusoft-mysql
```

### 删除所有容器
```bash
docker rm -f edusoft-frontend edusoft-ai-service edusoft-learning-service edusoft-content-service edusoft-course-service edusoft-user-service edusoft-mysql
```

### 清理网络和数据卷
```bash
# 删除网络
docker network rm edusoft-network

# 删除数据卷（⚠️ 会丢失数据库数据）
docker volume rm edusoft-mysql-data
```

## 🚨 故障排除

### 常见问题

#### 1. 端口被占用
```bash
# 查看端口占用
netstat -tulpn | grep :3000

# 如果端口被占用，可以修改端口映射
docker run -p 3001:80 fankeqing/edusoft:frontend
```

#### 2. 容器启动失败
```bash
# 查看容器日志
docker logs <container-name>

# 检查是否是内存不足
docker stats
```

#### 3. 数据库连接失败
```bash
# 确保数据库容器完全启动
docker logs edusoft-mysql | grep "ready for connections"

# 如果没看到，等待更长时间或重启数据库
docker restart edusoft-mysql
```

#### 4. 服务间无法通信
```bash
# 检查网络
docker network inspect edusoft-network

# 检查容器是否在同一网络
docker inspect edusoft-user-service | grep NetworkMode
```

### 诊断步骤

1. **检查镜像是否拉取成功**
   ```bash
   docker images | grep fankeqing/edusoft
   ```

2. **检查容器启动顺序**
   - 必须先启动数据库，等待完全启动后再启动其他服务

3. **检查环境变量**
   ```bash
   docker inspect edusoft-user-service | grep -A 10 Env
   ```

4. **检查网络连接**
   ```bash
   docker exec edusoft-user-service ping edusoft-mysql
   ```
