## 各服务职责详细说明

### 1. 用户服务 (User Service)

职责：

- 用户注册、登录、认证

- 用户信息管理

- 权限和角色管理

- 用户状态管理

包含功能：

- 用户管理

- 认证授权

- 角色权限

### 2. 课程服务 (Course Service)

职责：

- 课程信息管理

- 班级管理

- 课程章节管理

- 学生导入管理

包含功能：

- 课程管理

- 班级管理

- 课程章节

- 学生导入

### 3. 学习服务 (Learning Service)

职责：

- 作业管理

- 练习管理

- 学习记录

- 成绩管理

包含功能：

- 作业系统

- 练习系统

- 学习记录

- 成绩统计

### 4. 内容服务 (Content Service)

职责：

- 文件管理

- 教学资源

- 通知管理

- 讨论区

包含功能：

- 文件上传下载

- 教学资源

- 系统通知

- 用户讨论

### 5. AI服务 (AI Service)

职责：

- AI助手

- 智能判题

- 内容生成

- 数据分析

包含功能：

- AI对话

- 智能判题

- 内容生成
## 服务间通信关系
```
API Gateway
    ├── User Service (认证、用户管理)
    ├── Course Service (课程、班级管理)
    ├── Learning Service (作业、练习管理)
    ├── Content Service (文件、通知、讨论)
    └── AI Service (AI功能)
```
服务间依赖：

- Course Service → User Service (用户信息)

- Learning Service → User Service (用户信息)

- Learning Service → Course Service (课程信息)

- Content Service → User Service (用户信息)

- AI Service → User Service (用户信息)

- AI Service → Learning Service (学习数据)
